# Creative Portfolio Website

A responsive portfolio starter built with plain HTML, CSS and JavaScript. No framework, build step or paid service required.

## Run it
1. Unzip the folder.
2. Open `index.html` in a browser. For a smoother editing workflow, open the folder in VS Code and use the Live Server extension.

## Personalise it
- Search `YOUR NAME` and replace it with your name.
- Change `YN` in the header/footer to your initials.
- Update the email address `hello@example.com`.
- Replace the Instagram and Behance URLs with your own profiles.
- Edit the six project cards in `index.html`: title, category, year and description.
- Replace the CSS-made artwork blocks with your actual project images if desired. To do that, add an image to an `assets` folder and set the card's `.project-image` background in CSS, or replace the artwork contents with an `<img>` element.
- Update the skills and software list to match what you actually use.

## Included
- Responsive desktop/mobile layout
- Sticky navigation and mobile menu
- Project category filtering
- Project detail modal
- Scroll reveal effects
- Contact links and social links
- Reduced-motion accessibility support

The contact link uses `mailto:`. It opens the visitor's email app; it does not send messages to a server. A real contact form needs a backend or a form service.
